# Checkliste 3D-Druck (systems-engineer, 2026-11-07, Quelle PROMPT_1 §2)

Status je Punkt: PASS / PARTIAL / FAIL / BLOCKED / NOT RUN mit Beleg.

- [ ] Druckbar ohne oder mit wenig Stützmaterial (Orientierung dokumentiert)
- [ ] Wandstärke ≥ 3 Perimeter der Düse
- [ ] Passungstoleranzen für Board, Akku, Taster, USB-C dokumentiert
- [ ] Teile ≤ 180 × 180 × 180 mm (REQ-056)
- [ ] Slice-Lauf mit Bambu Studio P2S erfolgreich (Log abgelegt)
- [ ] Akku/Board fixiert für 1-m-Fall (REQ-057)
